# Performative Prediction and Intervention Contamination V1

Status: CROSS-DISCIPLINARY RESEARCH / SPECULATIVE_MODEL SUPPORT

## Why this matters

Testament's controller hypothesis contains a specific causal structure:

1. a predictor forecasts an outcome;
2. the forecast drives an intervention;
3. the intervention changes the agent/environment;
4. the changed state alters the outcome;
5. prediction and control can become entangled.

This structure is not unique to theology or simulation fiction.

Modern machine-learning research calls a closely related phenomenon **performative prediction**.

## Performative prediction

Perdomo, Zrnic, Mendler-Dünner and Hardt define performative prediction as the setting where deployment of a predictive model changes the distribution of the outcomes it is attempting to predict.

Reference:
- Perdomo et al., "Performative Prediction," ICML 2020:
  https://proceedings.mlr.press/v119/perdomo20a.html

Their core point is directly relevant:
a prediction used to make consequential decisions can become a causal input to its own target.

## Stateful feedback

Brown, Hod and Kalemaj extend the framework to a stateful world in which the population's response depends both on the current prediction/model and the current state of the population.

Reference:
- "Performative Prediction in a Stateful World":
  https://proceedings.mlr.press/v151/brown22a.html

This is closer to Testament's imagined controller:
an intervention changes not only one outcome but the state from which later predictions are made.

## Self-fulfilling and self-negating prediction

Older social-science literature treats both:
- self-fulfilling prediction;
- self-defeating/self-negating prediction;
as forms of reflexive or self-altering prediction.

Reference:
- "Do self-fulfilling prophecies improve or degrade predictive accuracy?"
  https://doi.org/10.1016/1053-5357(93)90017-F

A 2025 machine-learning paper explicitly treats self-fulfilling predictive systems as ethically significant because deployed forecasts can steer outcomes.

Reference:
- Khosrowi, Ahlers & van Basshuysen, "We Need to Talk About Self-Fulfilling Predictions":
  https://proceedings.mlr.press/v294/khosrowi25a.html

## Self-prophecy analogue

Experimental social-psychology literature reports that simply asking a person to predict whether they will perform an action can alter the probability of that action.

Reference:
- "Social Influence by Requesting Self-Prophecy":
  https://doi.org/10.1207/s15327663jcp0801_03

This does not imply supernatural prophecy.

It establishes an ordinary mechanism by which information about a possible future can change future behavior.

## Control-theory layer

Behavioral control theory models agents as acting to keep perceived variables near internal reference values, with feedback and conflict possible between control systems.

Reference:
- Warren Mansell, "Changing Behavior Using Control Theory":
  https://www.cambridge.org/core/books/abs/handbook-of-behavior-change/changing-behavior-using-control-theory/6F7BD075E7046390F126A4F445A7B02A

This is another useful analogue:
a corrective signal enters an already active control system rather than a passive object.

## What this supports

These literatures support the **coherence** of:
- prediction affecting the predicted system;
- warning altering behavior;
- intervention causing distribution shift;
- repeated correction seeking a new equilibrium;
- prediction accuracy and social welfare/control objectives diverging.

They do not support:
- existence of an external simulation controller;
- ancient prophetic voices being predictive interventions;
- divine hiddenness as a literal software patch.

## Stronger project formulation

The controller hypothesis should therefore be stated without mystical ambiguity:

> A sufficiently predictive supervisory system can lose causal validity when it communicates or acts on a forecast, because the intervention becomes part of the state transition being forecast.

That is a real systems problem.

The theological move begins only when we hypothesize that some reported revelations are instances of such intervention.

## Failure modes

A controller attempting to prevent X may:
- make X salient;
- alter incentives;
- cause fear;
- create authority structures;
- trigger opposition;
- change social coordination;
- cause agents to overcorrect;
- cause a self-negating outcome;
- cause a self-fulfilling outcome;
- force continuous retraining because the target distribution changes.

## Withdrawal-patch implication

A rational controller facing severe performativity may decide that less overt intervention produces cleaner observation or better outcomes.

That is a plausible engineering response **within the hypothetical**.

It still provides no evidence that historical divine hiddenness was caused this way.

## Book VII consequence

"The Controller's Mistake" now has a legitimate control/prediction literature beneath the analogy rather than being pure metaphor.

The final text should explicitly distinguish:
- established performativity;
- speculative extension to host-level control;
- theological interpretation of religious history.
