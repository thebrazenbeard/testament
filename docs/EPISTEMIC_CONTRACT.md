# Epistemic Contract

Testament inherits On-Theo's evidence discipline and adds authorial layers needed for literature.

## Evidence classes

- PRIMARY_TEXT — what an identified source says.
- MATERIAL_EVIDENCE — manuscript, inscription, coin, archaeology, physical remains.
- HISTORICAL_RECONSTRUCTION — inference about earlier people/events.
- LATER_TRADITION — later community memory or claim.
- SCHOLARLY_INTERPRETATION — attributed academic analysis.
- PROJECT_INFERENCE — our explicit reasoning.
- SPECULATIVE_MODEL — simulation/metaphysical/system model.
- UNKNOWN — insufficient or inaccessible evidence.
- AUTHORED_CONSTRUCTION — invented literary connective tissue.
- SYMBOLIC_SYNTHESIS — deliberate literary convergence of non-identical traditions.

## Date clocks

Never silently merge:
1. claimed event date;
2. source/composition date;
3. physical witness date;
4. modern edition/access date when relevant.

## Quotation rule

Ancient wording should be quoted sparingly and from a traceable edition/translation. When the manuscript puts new dialogue in an ancient person's mouth, the apparatus must classify it as authored construction even when it paraphrases source ideas.

## Contradiction rule

Contradictions may be:
- retained side by side;
- narrated as competing memories;
- resolved only when the evidence supports a resolution;
- used literarily without pretending the literary solution is historical proof.

## Confidence rule

Confidence applies to the exact proposition asserted.

"Mark contains X" can be high confidence while "X happened exactly as Mark narrates" remains unresolved.
