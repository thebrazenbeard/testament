# Research-to-Manuscript Workflow

## 1. Ask a scene-level question

Example:
"What can the book responsibly depict about Yeshua's baptism?"

Do not begin with the scene you want to write.

## 2. Pull upstream evidence

Check:
- On-Theo claim/source/witness records;
- exact upstream commit;
- primary text;
- manuscript/witness issues;
- material context;
- serious scholarship;
- opposing reconstruction.

## 3. Freeze the proposition set

Separate:
- textual facts;
- contextual facts;
- historical reconstruction;
- later tradition;
- unknowns.

## 4. Build scene packet

Use apparatus/SCENE_PACKET_TEMPLATE.md.

No prose drafting before the scene packet can state the construction budget.

## 5. Draft

The author may now:
- compress chronology;
- invent dialogue;
- supply sensory detail;
- choose viewpoint;
- juxtapose traditions;
- create symbolic motifs.

Each invention remains tagged.

## 6. Review

Required before a scene is treated as mature:
- source review;
- chronology review;
- contradiction review;
- bias/apologetics review;
- simulation-backprojection review;
- prose review.

## 7. Freeze passage provenance

Bind the passage to exact upstream refs and source notes.

A later upstream correction reopens the affected passage.
