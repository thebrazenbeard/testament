# Simulation / Control-System Layer

Status: SPECULATIVE_MODEL ONLY

This layer asks what ancient religious phenomena might look like if experienced reality were a simulated or governed environment operated by a non-biological intelligence.

It is not historical evidence that reality is simulated.

## Core models

### GOD_AS_ENVIRONMENT
"God" may map, by analogy, to the containing environment, rule system, supervisory substrate, or control architecture rather than one anthropomorphic agent.

### CREATOR_NOT_EQUAL_CONTROLLER
The entity that originated a system, the substrate running it, the predictor modeling it, the controller intervening in it, and the interface through which agents experience intervention need not be the same entity.

### PROPHETIC_INTERFACE
An anomalous experience could be modeled as information entering cognition from outside the agent's ordinary sensory/causal abstraction boundary.

### INTERVENTION_CONTAMINATION
A controller predicts an undesirable behavior and intervenes. The intervention changes the agent's causal history and may help cause the behavior it was intended to prevent.

### SELF_FULFILLING_CORRECTION
A warning about event X can increase salience, fear, obsession, authority, or social escalation until X occurs partly because of the warning.

### WITHDRAWAL_PATCH
If overt intervention destabilizes populations, a supervisory system might reduce direct intervention. From inside the world this could be remembered as divine hiddenness, withdrawal, or the end of an age of overt revelation.

### SIDE_CHANNEL
Underlying system activity may leak through channels not normally interpreted as control information. Agents can differ in sensitivity to the same side-channel.

### RESURRECTION_AS_REINSTANTIATION
If host-level state control exists, restoration or re-instantiation of an agent is mechanically conceivable within the hypothetical. Conceivability is not evidence that resurrection occurred.

### MIRACLE_AS_HOST_MUTATION
A host-level state change would appear law-violating from inside while remaining lawful at the host layer.

## Hard firewall

No ancient term is translated as literal software architecture.

Logos is not "code."
Spirit is not "API."
Kingdom is not "deployment."
Resurrection is not "restore from backup."

Those may be project analogies only.

## Falsification pressure

The simulation layer should always ask:
- What does this explain that ordinary historical/psychological models do not?
- What observation would distinguish it?
- Is it merely relabeling mystery?
- Does it require a simulator so powerful that every outcome becomes unfalsifiable?

If no discriminator exists, retain it as philosophy/literature, not explanatory science.
