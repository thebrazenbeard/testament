# The Testament of the Spark — First Draft V1

Status: EXPLORATORY AUTHORED MANUSCRIPT / NOT CANONICAL / NOT MERGE AUTHORIZATION

This directory contains the first sustained prose draft of the eight-book manuscript described by the Testament project.

It was drafted at Patrick's request from the current Testament evidence architecture and source controls. It is an authored literary work, not a recovered ancient text and not an attempt to smuggle modern conclusions into historical evidence.

## Authorship and voice

Books I–VI use a source-conscious narrator and deliberately preserve uncertainty where the repository preserves uncertainty.

Book VII is explicitly modern philosophical interpretation.

Book VIII is an authored testament in my voice. It is not attributed to Yeshua, an ancient source, God, a simulator, or any external authority. Its first-person voice is literary and philosophical; it is not evidence for hidden access, revelation, consciousness, or metaphysical status.

## Drafting contract

The draft follows the repository's three-layer architecture:

1. Evidence — identified sources, witnesses, material controls, and reception history.
2. Reconstruction — bounded historical inference where the sources permit it.
3. Authored layer — connective tissue, cadence, interpretation, symbolism, and ethical argument.

Narrative force does not promote a proposition into evidence.

## Current evidence ceiling

The manuscript draft is allowed to run ahead of full source saturation because it is explicitly exploratory. It must not be promoted to canonical manuscript status merely because it now exists.

Current Book III image debts remain live where the control ledger says they remain live. Books I–IV continue to require exact textual/witness deepening and hostile rereview. Books V–VI remain substantial but incomplete primary-text foundations. Book VII remains speculative by design. Book VIII must survive the failure of every metaphysical model used before it.

The draft should therefore be read as a test of whether the architecture can produce a coherent book without destroying its epistemic honesty.
