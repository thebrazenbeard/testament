# Scene Evidence Packet Template

## Identity
- scene_id:
- proposed_book:
- proposed_chapter:
- working_title:

## Historical question
What real event, setting, teaching, or reception claim is this scene attempting to represent?

## Source inventory
For each source:
- source ID / exact citation;
- source date;
- witness date if relevant;
- independence/dependence;
- what the source actually says;
- what it does not establish.

## Material/context inventory
- geography;
- archaeology;
- political chronology;
- social/economic setting;
- language;
- ritual/legal background.

## Conflicts
List incompatible or materially different versions without harmonizing them.

## Reconstruction
State the minimum defensible reconstruction.

## Authored construction budget
Explicitly list:
- dialogue invented;
- interior thoughts invented;
- chronology compressed;
- characters composited;
- location inferred;
- symbolism added.

## Simulation/speculative overlay
Allowed only after the historical reconstruction is written independently.

## Stop condition
If the scene requires pretending an unknown fact is known, redesign the scene.
