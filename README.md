# Testament

Testament is a source-critical literary project centered on Jesus/Yeshua and the traditions that formed around him.

It draws across Jewish, Christian, apocryphal, mystical, Islamic, historical, and explicitly speculative material to explore divinity, human agency, memory, interpretation, and the nature of reality.

## Method

The project should keep distinct:

- historical or textual source claims;
- literary reconstruction;
- theological interpretation;
- later tradition;
- speculation used as narrative or hypothesis.

A source appearing in the project does not make every claim in that source historically established.

## Current status

The current `main` branch is still a lightweight project shell. The README defines the literary/research direction; it does not by itself represent a completed manuscript, complete source registry, or settled historical reconstruction.

## Related work

Source-critical research can inform Testament without collapsing research notes and literary output into the same evidence class.
